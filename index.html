pdf.stoetz.msAssemble PDFs and images into one structured document.

Cover page, table of contents, section dividers, bookmarks and page numbers, from one YAML file.

User Guide
Configuration
Example PDF

Declarative

Describe the document in one YAML file — sections, PDFs, images, cover, table of contents and page numbers. Edit it or replace a source, run one command, and everything is regenerated with correct page references.

Offline

Everything runs locally on your machine. Nothing is uploaded, templates cannot load remote resources, and the same inputs produce a byte-identical PDF.

Open-source

Apache-2.0 licensed and built on WeasyPrint, pikepdf and Jinja. Covers, dividers and the table of contents are plain HTML and CSS templates you can change.
